# Test data

`GeoIP2-Country-Test.mmdb` — a fabricated GeoIP2 Country database from MaxMind's
[MaxMind-DB](https://github.com/maxmind/MaxMind-DB) repository
(`test-data/GeoIP2-Country-Test.mmdb`), licensed Apache-2.0. It contains a
handful of synthetic IP → country mappings and is used only by
`gsp-core`'s geo-filter unit tests. Not a real geolocation database.
